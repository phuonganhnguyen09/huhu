Hệ thống Minh họa Đạo hàm

Hàm số: f(x) = -x⁴ + 4x³ - 3x² + 2x + 1

Tính đạo hàm tại điểm x = -1

Quy tắc tổng/hiệu

f'(x) = (-x⁴)' + (4x³)' - (3x²)' + (2x)' + (1)'

(-x⁴)'

-4x³

(4x³)'

12x²

-(3x²)'

-6x

(2x)'

2

(1)'

0

Kết quả Đạo hàm f'(x)

f'(x) = -4x³ + 12x² - 6x + 2

Tính giá trị tại x = -1

Thay x = -1 vào biểu thức:

f'(-1) = -4(-1)³ + 12(-1)² - 6(-1) + 2
f'(-1) = -4(-1) + 12(1) + 6 + 2
f'(-1) = 4 + 12 + 6 + 2
f'(-1) = 24

Quy tắc đã dùng:

  • (xⁿ)' = n.xⁿ⁻¹
  • (k.u)' = k.u'
  • (u ± v)' = u' ± v'
  • (C)' = 0
